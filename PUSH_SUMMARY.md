## 🚀 Usage Instructions

### Clone the Smart Contract Repo
```bash
git clone https://github.com/Afro-Pay/afropay-stellar-contract.git
cd afropay-stellar-contract
cargo build --release --target wasm32-unknown-unknown
```

### Build & Deploy
```bash
# Optimize WASM
wasm-opt -Oz target/wasm32-unknown-unknown/release/afropay_stellar_contract.wasm -o afropay.wasm

# Deploy to testnet
stellar contract deploy \
  --wasm afropay.wasm \
  --network testnet \
  --issuer admin-testnet
```

### For the Full Platform (Once Access Granted)
```bash
git clone https://github.com/dev-fatima-24/AfroPay-Stellar.git
cd AfroPay-Stellar
git checkout feat/soroban-contract-complete

# Or follow QUICKSTART.md for local setup
docker-compose up -d

```
